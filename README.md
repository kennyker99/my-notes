# my-notes 📚 个人笔记归档

个人笔记与知识管理仓库，用于长期保存日常记录、项目资料、知识库内容、旅行计划与灵感碎片。

## 目录结构

| 目录 | 用途 |
|---|---|
| [`日常/`](./日常) | 日常笔记、随手记录、周期性总结 |
| [`项目/`](./项目) | 项目文档、创作企划、进度追踪 |
| [`知识库/`](./知识库) | 长期知识整理、学习笔记、参考资料 |
| [`旅行/`](./旅行) | 旅行计划、行程安排、打包清单 |
| [`灵感/`](./灵感) | 灵感碎片、素材收集、视觉记忆 |

## 使用建议

- 笔记以 Markdown（`.md`）为主，方便版本追踪和搜索。
- 图片等附件可放在对应目录下的 `assets/` 子文件夹中，用相对路径引用。
- 每个目录下已有一份 `README.md` 说明其用途，可直接在里面按需要新建笔记文件，或替换成自己的内容。

## MindBoard 看板工具

仓库里的 [`mindboard.html`](./mindboard.html) 是一个仿 Milanote 的知识管理 / 思维导图 / 创作企划 / 视觉记忆 / 旅行计划看板工具（单文件，无需安装，浏览器直接打开即可用）。

**功能**：无限画布拖拽卡片、便签/清单/看板列/图片/文件/链接/子看板等多种卡片类型、卡片间连线画思维导图、多选框选/撤销重做/回收站、富文本便签、右键菜单、全局内容搜索、内置模板（思维导图/创作企划/视觉记忆/旅行计划/头脑风暴/个人知识库/内容日历）。数据自动保存在浏览器本地（localStorage），也支持导出/导入 JSON 备份。

**如何打开**：
- 本地：把仓库 clone 或下载下来，直接双击 `mindboard.html` 用浏览器打开。
- 在线：由于本仓库是私有的，GitHub Pages 需要付费版才能给私有仓库开启在线访问；如果想要一个免登录就能打开的在线链接，需要把仓库设为 Public（会公开笔记内容）或升级到 GitHub Pro 及以上。

建议把看板导出的 JSON 存到 `项目/` 或 `旅行/` 目录下作为备份归档。
