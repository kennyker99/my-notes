拖动小圆点可在卡片之间画连线 · 右键单击可打开菜单
框选 — 在空白处拖拽画出选框，多选卡片
平移画布 — 双指滚动 / 按住空格拖拽 / 鼠标中键拖拽
缩放 — Ctrl/⌘ + 滚轮，或右上角按钮
移动卡片 — 拖动卡片顶部色条（多选可整体拖动）
连线 — 拖动卡片边缘的橙色圆点到另一张卡片
调整连线弧度 — 选中连线后拖动中间的小圆点，右键连线选"恢复自动弧度"
编辑连线标签 — 双击连线（或右键选"编辑标签"），支持多行文字
加选 — Shift/Ctrl 点击卡片可加入多选
右键菜单 — 卡片或空白处右键可快捷操作
富文本 — 便签/标题内选中文字可加粗/斜体/列表
新建便签 — 双击空白处
移到回收站 — 选中后按 Delete / Backspace
重复 — 选中后按 Ctrl/⌘ + D
剪切/拷贝/粘贴 — Ctrl/⌘ + X / C / V（可跨看板粘贴）
锁定位置 — 右键卡片菜单里可锁定，防止误拖动
撤销/重做 — Ctrl/⌘ + Z ／ Ctrl/⌘ + Shift + Z
粘贴图片 — 复制图片后 Ctrl/⌘ + V
拖放文件 — 直接从系统拖拽文件到画布
